# CACTUS IST v1.52 review artifact

This archive accompanies the CACTUS Information and Software Technology (IST) manuscript v1.52. The review ZIP regenerates the structured manuscript, value ledger, tables and figures offline from fixed projections and runs synthetic admission-checker regression. Its recorded partial audit reproduced 29 exclusion decisions from original bundles. Complete original-run re-admission and model/evaluator replay require separate access to the retained research archive. The release contains a sanitized review artifact.

Download and extract the review ZIP. With the dependencies listed in the archive installed, run `python scripts/reproduce_review_artifact.py all` from the extracted directory. See the archive README for details.

The source snapshot and release asset contain the same review ZIP. Its SHA-256 is `e4fc525697f001c79f0c7c4f6c32c6556e1cf1578efa2076a7f9cb2ae850a164`.
